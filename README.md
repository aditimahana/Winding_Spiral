# Winding Spiral 1

A Python graphics exercise that uses the Turtle module to create a winding spiral pattern. By turning 91 degrees instead of 90 degrees after each movement, the program produces a more curved, winding effect rather than a traditional square spiral.

## Concepts Learned
- Importing and using the `turtle` module
- Creating and controlling a Turtle pen
- Using `for` loops and `range()`
- Controlling movement with `forward()` and `left()`
- Experimenting with angles to create different geometric patterns

## How to Run
1. Make sure Python is installed.
2. Run `WindingSpiral1.py`.
3. Watch as the turtle draws the winding spiral!

## Code Highlights
- `t.speed(0)` sets the drawing speed to the fastest setting.
- `t.forward(x)` gradually increases the movement distance.
- `t.left(91)` creates a 91-degree turn, producing the winding spiral effect.
